# Forma — CV & Resume Builder

A browser-based CV and resume builder with six starter designs: three CV templates and three resume templates. Visitors can preview a design, enter their own information, and export a PDF.

## Start

Open `index.html` in a local web server or publish the repository with GitHub Pages.

## How it works

1. Choose a CV or Resume template and open its preview.
2. Select **สร้าง** to open the editor for that design.
3. Add contact details, summary, education, skills, experience, and projects.
4. Save the draft or download a PDF preview.

Each design keeps its own draft in the visitor's browser using `localStorage`. No account is required and this starter version does not send resume data to a server.
